# build/code/ado

These ado files should be placed in your personal ado files folder on your system to run the programs in this project. Directions on where to put (copy and paste) the ado files in the ado folder are below:

1. In Stata, enter `sysdir`. It will tell you where your personal ado files ago under PERSONAL.
2. Create the directories fodlers if they do not already exist under the suggested path on your system.
3. Add all of the ado files in the ado folder to that location
